# rmoriz Homebrew Tools

A personal [Homebrew](https://brew.sh) tap for tools not available in homebrew/core.

`brew install rmoriz/tools/<formula>`

Or `brew tap rmoriz/tools` and then `brew install <formula>`.

## Formulae

| Formula | Version | Description |
| --- | --- | --- |
| `git-time` | 0.3.0 | Verifiable RFC 3161 timestamps inside git commits |
| `pdns` | 5.1.5 | Authoritative nameserver |
| `dublin-traceroute` | 0.4.2 | NAT-aware multipath tracerouting tool |
