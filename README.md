# rmoriz Homebrew Tools

A personal [Homebrew](https://brew.sh) tap for tools not available in homebrew/core.

`brew install rmoriz/tools/<formula>`

Or `brew tap rmoriz/tools` and then `brew install <formula>`.

## Formulae

| Formula | Version | Description | Install |
| --- | --- | --- | --- |
| [`git-time`](Formula/git-time.rb) | 0.3.1 | [Verifiable RFC 3161 timestamps inside git commits](https://github.com/rmoriz/git-time) | `brew install rmoriz/tools/git-time` |
| [`pdns`](Formula/pdns.rb) | 5.1.5 | [Authoritative nameserver](https://www.powerdns.com) | `brew install rmoriz/tools/pdns` |
| [`dublin-traceroute`](Formula/dublin-traceroute.rb) | 0.4.2 | [NAT-aware multipath tracerouting tool](https://dublin-traceroute.net) | `brew install rmoriz/tools/dublin-traceroute` |
